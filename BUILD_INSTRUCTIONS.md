# Build Instructions - Sally Mobile

## Prerequisites

1. **Expo Account**
   - Create account at https://expo.dev
   - Verify email address

2. **Install EAS CLI**
   ```bash
   npm install -g eas-cli
   ```

3. **Login to Expo**
   ```bash
   eas login
   ```

## Initial Setup

### 1. Configure EAS Project

```bash
cd sally-mobile
eas build:configure
```

This will:
- Link your project to your Expo account
- Generate a project ID
- Update app.json with EAS configuration

### 2. Update Project ID

After running `eas build:configure`, update `app.json`:

```json
"extra": {
  "eas": {
    "projectId": "YOUR_PROJECT_ID_HERE"
  }
}
```

## Building for Android

### Preview Build (APK for Testing)

```bash
eas build --platform android --profile preview
```

- Generates: APK file
- Use for: Testing on physical devices
- Download: From Expo dashboard or CLI
- Install: Transfer APK to device and install

### Production Build (AAB for Google Play)

```bash
eas build --platform android --profile production
```

- Generates: AAB (Android App Bundle)
- Use for: Google Play Store submission
- Signing: Automatically handled by EAS
- Download: From Expo dashboard

### Production APK (Alternative)

```bash
eas build --platform android --profile production-apk
```

- Generates: APK file (production-ready)
- Use for: Direct distribution or testing production build
- Larger file size than AAB

## Building for iOS

### Preview Build

```bash
eas build --platform ios --profile preview
```

### Production Build

```bash
eas build --platform ios --profile production
```

**Note:** iOS builds require:
- Apple Developer account ($99/year)
- App Store Connect credentials
- Provisioning profiles (auto-generated by EAS)

## Build Profiles Explained

### Development
- For development with Expo Go
- Includes dev tools
- Not for distribution

### Preview
- For internal testing
- APK format (Android)
- Smaller, faster builds
- No app store submission

### Production
- For app store submission
- AAB format (Android)
- IPA format (iOS)
- Optimized and minified
- Code signing included

### Production-APK
- Production-ready APK
- For direct distribution
- Useful for testing production build before store submission

## Monitoring Builds

### Check Build Status

```bash
eas build:list
```

### View Build Details

```bash
eas build:view [BUILD_ID]
```

### Download Build

Builds are automatically available in:
- Expo dashboard: https://expo.dev/accounts/[username]/projects/sally-mobile/builds
- CLI: `eas build:download [BUILD_ID]`

## Credentials Management

### Android Signing

EAS automatically generates and manages:
- Keystore
- Key alias
- Key password
- Keystore password

**Important:** EAS securely stores these credentials. You can download them if needed:

```bash
eas credentials
```

### iOS Certificates

EAS automatically generates:
- Distribution certificate
- Provisioning profiles
- Push notification certificates (if needed)

## Environment Variables

### Set Build-Time Variables

```bash
eas secret:create --scope project --name OPENAI_API_KEY --value your_api_key_here
```

### List Secrets

```bash
eas secret:list
```

## Troubleshooting

### Build Failed

1. Check build logs:
   ```bash
   eas build:view [BUILD_ID]
   ```

2. Common issues:
   - Missing dependencies: Run `pnpm install`
   - Invalid app.json: Validate JSON syntax
   - Asset issues: Ensure all assets exist

### Clear Build Cache

```bash
eas build --platform android --clear-cache
```

### Update Dependencies

```bash
pnpm update
```

2. **Test on physical device** (APK)

## Useful Commands

```bash
# Build for both platforms
eas build --platform all --profile production

# Build with specific runtime version
eas build --platform android --profile production --runtime-version 1.0.0

# Build without submitting
eas build --platform android --profile production --no-wait

# Submit existing build to store
eas submit --platform android --latest

# Check account status
eas whoami

# View project info
eas project:info
```
